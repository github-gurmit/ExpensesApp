# Daily Expenses (installable app)

## GitHub par upload
1. github.com par New repository banao (naam: expenses, Public).
2. "Add file > Upload files" me is folder ki saari files daalo (index.html, jspdf.umd.min.js, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) aur Commit karo.
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root) > Save.
4. 1-2 minute baad link milega: https://USERNAME.github.io/expenses/

## Phone me install
- Android Chrome: menu (3 dots) > Install app / Add to Home screen.
- iPhone Safari: Share > Add to Home Screen.

## Update karna ho to
index.html badalne ke baad sw.js me "kharcha-v1" ko "kharcha-v2" kar do, warna phone purana version dikhata rahega.
